# Expense Tracker Android App 📱

A simple and functional Android application for daily tracking and monitoring of personal expenses.

## 📝 Description
The application allows users to record their spending at the end of each day. It provides analytical statistics on a weekly and monthly basis, assisting in better financial management.

## ✨ Features
* **Daily Recording:** Easy entry of expenses per day.
* **Statistical Analysis:** * Total expenses (Weekly/Monthly).
    * Average expenses per day and per week.
    * Identification of the day or week with the highest and lowest spending.
* **Local Storage:** Implementation is based exclusively on the use of **Shared Preferences** for data storage.

## 🛠️ Technical Specifications
* **Platform:** Android
* **Storage:** Shared Preferences
* **Language:** Java
* **IDE:** Android Studio
